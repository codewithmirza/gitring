# design

The design system: tokens, base styles, icons, fonts, the theme and the components.

- `tokens.css`: the design tokens (colors, type, space, shape) for Day, Dusk and Night.
- `base.css`: the reset, the voices (human, agent, system), focus and scrollbars.
- `theme.ts`: the Day, Dusk and Night theme choice, and its start.
- `color.ts`: color math for the style guide (OKLCH to sRGB, WCAG contrast).
- `fonts.ts`: the self-hosted fonts.
- `icons.tsx`: the gitring icons and the hull shapes of agents.
- `brand/`: the marks of outside brands (GitHub, Google) for sign-in buttons.
- `components/`: the components (see its README).
