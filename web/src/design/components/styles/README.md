# components/styles

The styles of the design system components. `../components.css` imports these files in this order. The order is part of the look (a later rule wins), so keep it.

- `controls.css`: Button, IconButton, Segmented and Field.
- `badges-panels.css`: Badge, Callsign, Panel and Row.
- `evidence-diff.css`: EvidenceBar, DiffView and PreviewFrame.
- `corrections.css`: CorrectionNotice, CourseCheckReadout and RangeIndicator.
- `feedback.css`: LogLine, Stat and Toast.
- `dialog-tabs.css`: Dialog and Drawer, Tabs, Tooltip and Kbd.
- `content-states.css`: CodeBlock and EmptyState.
- `popovers.css`: Popover, Menu, Inline confirm and Inline panel.
- `loading-signin.css`: Skeleton, the sign-in buttons, ProgressRule, keyframes and the line request form.
