# views/logbook

The parts of the history page. `../LogbookView.tsx` composes them. The styles are in `../logbook.css`.

- `links.ts`: app links that keep the project of the address.
- `Row.tsx`: one row of the list of merges.
- `Evidence.tsx`: the merge ladder, the evidence of a conflict check and the table of checks.
- `WhyTrail.tsx`: the record of one merge, step by step.
