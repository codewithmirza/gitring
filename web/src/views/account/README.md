# views/account

The sections of the account page. `../AccountView.tsx` composes them and holds the profile.

- `format.ts`: the host of a URL and a short date.
- `AnswersIn.tsx`: where the person answers merge questions.
- `Passkeys.tsx`: the passkeys of the person.
- `SignInMethods.tsx`: Google, GitHub and the GitHub connection.
- `ConnectedApps.tsx`: the apps allowed through OAuth.
- `ApiKeys.tsx`: personal API keys.
