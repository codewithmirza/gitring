# newproject/steps

The second step of a new project, one file for each source. Import from `../steps` (the front door), not from this folder.

- `shared.tsx`: the props and the parts that every step shares (head, row, problem box, submit button).
- `DescribeStep.tsx`: "Describe what you want to build".
- `TemplateStep.tsx`: a starter template.
- `GithubStep.tsx`: a GitHub repository.
- `UrlStep.tsx`: any public git URL.
- `UploadStep.tsx`: a folder upload.
- `PlainStep.tsx`: "Push with git" and "Empty project".
