# replay/styles

The styles of the replay page. `../replay.css` imports these files in this order. The order is part of the look (a later rule wins), so keep it.

- `stage.css`: the kiosk mode and the stage with its overlays.
- `caption-inside.css`: the caption, the Inside gitring panel, the distance ladder and the compose graph.
- `controls-responsive.css`: the controls, the map effects and the rules for short and small screens.
