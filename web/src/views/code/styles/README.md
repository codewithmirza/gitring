# code/styles

The styles of the code page. `../code.css` imports these files in this order. The order is part of the look (a later rule wins), so keep it.

- `syntax.css`: the syntax colors in each theme.
- `toolbar-tree.css`: the layout, the toolbar and the file tree.
- `file-diff.css`: the file header, the lines with their gutter marks, and the diff.
- `states-touch.css`: the pickers, a ref without a file, loading shapes, touch and phone rules, line requests and Clone.
