# app/styles

The styles of the app shell. `../app.css` imports these files in this order. The order is part of the look (a later rule wins), so keep it.

- `shell-topbar.css`: the app grid, the boot screen, the top bar, the view tabs and the search trigger.
- `popovers.css`: connection, decisions, project picker, command palette, shortcuts and sign-in.
- `rails.css`: the chart view, the intents rail, the task composer, the traffic rail, vessel detail, the radio log and the launch control.
- `page-responsive.css`: the generic page, the rules for tablets, phones and touch, and the back link.
- `accounts.css`: the project switcher, the person menu, the watch banner and the inbox button.
